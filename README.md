# ChemCompass

Practice-paper generator for **CBSE Class 12 Chemistry (043)**.

Questions are taken from:

- [CBSE Question Bank Class XII](https://cbseacademic.nic.in/qbclass12.html) — Chemistry PDF
- [Additional Practice Questions](https://cbseacademic.nic.in/additionalPQ.html) — Chemistry papers 2021–24

## Run locally

Needs Node 18+.

```bash
npm install
npm run dev
```

Open the printed URL, pick chapters and sources, then **Generate paper**. Use **Print / save PDF** for a hard copy.

## Notes

- Diagrams in the original PDFs are not redrawn; affected items include a figure note.
- Answer keys follow the published marking schemes where they could be recovered from the PDFs.
- CBSE holds copyright in the source papers; this app is a study aid, not an official board product.
